Easily Extendible Shell (EESH)

This was a passion project that I had written in the summer of 2024. It was my first foray into systems level programming, and it was a super interesting deep dive into writing programs without abstractions. It was a ton fun and cool to work on. If I rewrote it now, I would change a lot, but it was a good learning experience.

Feel free to go to this link to have a look at the git repo.

libalex

This was another systems level programming project, which was an expansion on EESH. This took my systems level programming to the next level: it was an attempt to write a more or less stripped down version of libc. -freestanding, -nostdlib, the whole nine yards. I'm continually working on this (when I have time!) and it is a really nice learning experience to deal with the basic problem of "how do I work with something when I have nothing?"

I have reincarnated this project in x86_64 instead of RISC-V.

Feel free to go to this link to have a look at the git repo. This is the original, worse RISC-V solution. The current one I am working on is here.

auto_tmux

My editor of choice is primarily VIM. I have used Emacs in the past, as well as VSCode, but something about the simplicity of VIM and the power of some choice plugins makes me giddy (for more, see this for more info). VIM and tmux go hand in hand. auto_tmux is a project that you can simply source into your .bashrc and it will automatically connect a new terminal to it's own tmux server. If you close one terminal, and open another, it will connect to the previous session. A very useful tool for myself, one that is on all my servers. Feel free to play around with it here.
