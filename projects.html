Void Linux

Void Linux has been my recent obsession, as it is a super barebones distribution that you can build on top of. In particular, it has a few very interesting things that I enjoy about it:

  1. No systemd. Systemd gets a lot of flak on the internet: some points are good, others are kind of bad. My main problem is bloat: if you have a Linux system, you want it (in my opinion) to be as lean as possible. Systemd is bloated: it attempts to a ton of things, which violates the UNIX philosophy. What they use instead is runit: I will touch on this below.
  2. xbps package manager. xbps is an excellent package manager: it is maintained by Void Linux itself. No apt, no dnf, no pacman. Obviously no package manager is perfect; nothing is. But xbps is great.
  3. Debian-esque rolling release. Very rare to have a borked update, unlike Arch. Not as slow though.

The Homelab

This is a writeup on my homelab. This is not current or at all supposed to be a manual on how to use my lab or how people should replicate it. Rather, I want this to be a place of learning: I for sure did!

First, we have to talk about hardware. My network is called luckducknet, and for good reason. I have two machines: luckduck1 and luckduck2. luckduck1 is the primary machine, and the specs are as follows:

  1. CPU: Intel Core i7-10700F. 2.9 GHz BEAST, back in the day. Great for server life.
  2. RAM: 3x Hyundai Electronics DDR4 8GB RAM. Absolutely atrocious: one stick is 3200 MHz while the other two is at 2400 MHz. Horrid.
  3. 1 TB Samsung NVMe, simply for OS and tools
  4. Graphics Card: NVIDIA GTX 2080 Super. Why? Cause this was my old gaming PC! What will I use it for???? WHO KNOWS!
  5. 3x 1 TB HDDs. 2x TOSHIBA MQ04ABF1, 1x WDC WD10JPVX-22J. More on this later.
The 3x 1 TB harddrives are for the real fun of this homelab: software RAID. I store all of my data on it.
